# UnityTemplate

新規Unityゲームを立ち上げるときに使用するテンプレート。

## Why?

Unityゲーム開発でよく使われるライブラリ、ミドルウェア、設定などをこちらのリポジトリで管理することで、  
新規プロジェクト作成時の手間を省くことができます。
